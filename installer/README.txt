Stjartgruppen - addon for WoW: Forever
======================================

TO INSTALL: double-click "Install Stjartgruppen.bat". That's it.
(You don't need to open the "files" folder. The installer uses it.)

Step by step (Windows):
1. Right-click the zip you downloaded and choose "Extract All...", then open the extracted folder.
2. Double-click "Install Stjartgruppen.bat".
   If Windows shows "Windows protected your PC", click "More info" and then "Run anyway".
   (It is a small script from a friend, not a signed program. You can open files\install.ps1
   in Notepad to see exactly what it does.)
3. The installer finds your World of Warcraft folder. If it can't, a folder picker opens:
   choose the World of Warcraft folder (the one that contains _forever_).
4. Restart the game fully, make sure Stjartgruppen is ticked under AddOns at character select,
   and type /sg in game.

Updating: download the newest zip from the same link and run the installer again.
It replaces the old version and keeps your settings.

Manual install instead: copy the Stjartgruppen folder from inside "files" into
World of Warcraft\_forever_\Interface\AddOns\
